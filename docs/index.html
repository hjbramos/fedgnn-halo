FedGNN-Halo

Um ambiente modular para examinar a perda e a recuperação de mensagens entre clientes na previsão em grafos.

Código e instruções · Notebooks

Comece com um experimento pequeno

O exemplo sintético funciona em CPU, com três clientes e sem baixar bases externas. Modelos, agrupamentos e hiperparâmetros são definidos em YAML.

python -m pip install -e ".[dev,notebooks,reproduction]"
fedgnn-halo --config examples/synthetic.yaml
jupyter lab notebooks/01_quickstart.ipynb

Consulte o README para criar o ambiente virtual e obter o projeto. O exemplo verifica a execução; não reproduz as tabelas da dissertação.

Modelos

LEConv, GRU, LSTM e DCRNN, com construção separada do carregamento de dados.

Treinamento

Centralizado, Local, FedAvg, FedProx, Ditto e FedGNN-Halo.

Agrupamentos

Partições contíguas, aleatórias, Leiden ou rótulos fornecidos pelo usuário.

O que o halo recupera

Os nós virtuais representam agregados dos históricos de vizinhos externos. A recuperação implementada é específica à arquitetura com uma camada LEConv, sob entradas e parâmetros comuns. Recuperar mensagens não garante melhora do erro após o treinamento federado.

Dados e alcance

Os carregadores atendem SUNT, METR-LA e PEMS-BAY. Os dados permanecem nas fontes originais. A simulação não implementa rede distribuída real nem proteção de privacidade dos agregados.
